## 安装说明

`PiP-Disabler.dll` 需与以下文件**同目录**放在 `BepInEx\plugins\PiP-Disabler\`：

```
PiP-Disabler.dll
pipdisabler_effect_shaders.bundle
pipdisabler_reticle_shaders.bundle
custom_mesh_surgery_settings.json      ← 按瞄具参数（82 条）
i18n\en.json  i18n\zh-CN.json  i18n\README.md
```

> 注意：源码按 **pluginDir 直接找文件名**，把 `.bundle` 放进 `Resources\Shaders\` 子目录会**静默失效**。
> 另注意：`[BepInPlugin]` 的 Version 必须是合法 `System.Version`（纯数字）。写成 `"1.5.0-mvp-4.1.5"` 这类带后缀的字符串会让 BepInEx **静默丢弃**该插件（且 TypeLoader 缓存会一直沿用这个错误结论）—— 本版本为 `"1.5.0"`。
